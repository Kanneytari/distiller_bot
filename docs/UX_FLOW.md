# UX Flow

Карта экранов и навигации Distiller Bot.

Цель интерфейса — сделать бота понятным без инструкций. Пользователь должен почти всегда понимать, что делать дальше, по тексту текущего экрана и 2–4 inline-кнопкам под ним.

## 1. Общие UX-принципы

1. Всё основное управление — через inline-кнопки.
2. Главное меню содержит только четыре раздела:
   - 🥃 Напитки
   - 📖 Рецепты
   - 🧮 Калькуляторы
   - ⚙️ Оборудование
3. Основные действия доступны за 1–2 нажатия.
4. На одном экране желательно не больше 4–5 смысловых действий.
5. Дополнительные действия прячутся в «Ещё», если без этого экран становится перегруженным.
6. Бот не спрашивает повторно данные, которые уже знает.
7. Если можно предложить готовый вариант — бот предлагает его кнопкой вместо ручного ввода.
8. Любой вложенный экран должен иметь понятный путь назад.
9. На большинстве экранов используются кнопки:
   - ← Назад
   - 🏠 Меню
10. После выполнения действия пользователь должен попадать в логичное состояние, а не в тупик.
11. Бот по возможности редактирует текущее сообщение вместо отправки большого количества новых сообщений.
12. Текст интерфейса короткий. Подробные пояснения показываются только по запросу.

# 2. Первый запуск

## Экран 2.1 — Приветствие

Первый запуск не должен превращаться в длинную регистрацию.

Пример:

> 🥃 Distiller Bot
>
> Рецепты, расчёты и журнал ваших напитков.
>
> Бот может запомнить ваше оборудование и использовать его в рецептах и калькуляторах.

Кнопки:

- 🚀 Начать

Переход:

`Начать → 2.2`

## Экран 2.2 — Оборудование сейчас или позже

> Сначала можно добавить основное оборудование — тогда бот сразу сможет подстраивать рецепты и расчёты под вас.

Кнопки:

- ⚙️ Добавить оборудование
- Пропустить

Переходы:

- `Добавить оборудование → 7.2`
- `Пропустить → 3.1`

Важно: оборудование не должно быть обязательным условием использования бота.

# 3. Главное меню

## Экран 3.1 — Главное меню

Главный экран должен быть максимально коротким.

Пример:

> 🥃 Distiller Bot
>
> Что хотите сделать?

Кнопки:

- 🥃 Напитки
- 📖 Рецепты
- 🧮 Калькуляторы
- ⚙️ Оборудование

Если есть активный напиток, полезно показать его над кнопками:

> Сейчас в работе:
> 🟡 Бурбон · брожение · 4 день

Но не добавлять отдельные кнопки статистики, напоминаний, запасов и настроек в главное меню. Они должны открываться из соответствующего контекста.

# 4. Напитки

## Экран 4.1 — Список напитков

Если напитков ещё нет:

> 🥃 Напитки
>
> Здесь будут ваши текущие и завершённые напитки.

Кнопки:

- ➕ Новый напиток
- 🏠 Меню

Если напитки есть:

> 🥃 Напитки
>
> 🟡 Бурбон · брожение · 4 день
> 🪵 Кальвадос · выдержка · 38 дней
> ✅ Сахарный дистиллят · готов

Кнопки:

- 🟡 Бурбон
- 🪵 Кальвадос
- ✅ Сахарный дистиллят
- ➕ Новый напиток
- 🏠 Меню

Если список большой — пагинация, но не показывать десятки кнопок сразу.

Переходы:

- `Напиток → 4.4`
- `Новый напиток → 4.2`

## Экран 4.2 — Как создать напиток

> ➕ Новый напиток
>
> Как хотите начать?

Кнопки:

- 📖 По рецепту
- ✏️ С нуля
- ← Назад

Переходы:

- `По рецепту → 5.1` в режиме выбора рецепта для нового напитка
- `С нуля → 4.3`

## Экран 4.3 — Быстрое создание с нуля

Не нужно сразу просить десять параметров.

Шаг 1:

> Как назовём напиток?

Пользователь вводит название текстом.

Шаг 2:

> Что это за напиток?

Кнопки, например:

- 🌾 Зерновой
- 🍎 Фруктовый
- 🍬 Сахарный
- 🌿 Настойка
- Другое

После этого напиток создаётся сразу. Все остальные параметры можно заполнить позже по мере процесса.

Переход:

`Создан → 4.4`

## Экран 4.4 — Карточка напитка

Это главный рабочий экран пользователя.

Пример:

> 🥃 Бурбон
>
> 🟡 Брожение · 4 день
> Начат: 25 августа
>
> Последний замер:
> Плотность: 1.026 · сегодня
>
> Следующее действие: проверить плотность

Основные кнопки:

- ➕ Замер
- ✅ Следующий этап
- 🔔 Напомнить
- ⋯ Ещё
- ← Напитки
- 🏠 Меню

Ключевой принцип: карточка должна показывать состояние и следующее логичное действие, а не всю накопленную историю.

## Экран 4.5 — Следующий этап

При нажатии `✅ Следующий этап` бот показывает только логичные варианты для текущего типа напитка и текущего состояния.

Пример:

> Текущий этап: брожение
>
> Перейти дальше?

Кнопки:

- ✅ Брожение завершено
- Выбрать другой этап
- ← Назад

После подтверждения бот обновляет статус и возвращает пользователя в карточку напитка.

## Экран 4.6 — Добавить замер

> ➕ Новый замер
>
> Что измерили?

Кнопки:

- 🌡 Температура
- 📏 Плотность
- 🥃 Крепость
- 💧 Объём
- 📝 Заметка
- ← Назад

После выбора бот запрашивает только значение.

Пример:

> Укажите крепость, %

После ввода:

> ✅ Замер сохранён
>
> Крепость: 68%

Кнопки:

- ➕ Ещё замер
- ← К напитку

Если единица измерения однозначна, пользователь её не вводит.

## Экран 4.7 — Напоминание

> 🔔 Напомнить
>
> О чём напомнить?

Бот может предложить контекстные варианты:

- Проверить плотность
- Проверить выдержку
- Следующий этап
- ✏️ Свой текст

После выбора:

> Когда напомнить?

Кнопки:

- Завтра
- Через 3 дня
- Через неделю
- 📅 Другая дата
- ← Назад

## Экран 4.8 — «Ещё» в напитке

Сюда выносятся редко используемые действия:

- 📋 Журнал
- 📖 Рецепт
- ⭐ Оценить результат
- ✏️ Изменить
- 🗑 Удалить
- ← Назад

Статистика конкретного напитка также может находиться здесь позже.

## Экран 4.9 — Журнал напитка

> 📋 Журнал · Бурбон
>
> 28 авг · Плотность 1.026
> 27 авг · Температура 24 °C
> 25 авг · Брожение начато

Кнопки:

- ← Ранее
- Позже →
- ← К напитку

Не делать отдельные экраны для каждого типа события без необходимости.

# 5. Рецепты

## Экран 5.1 — Рецепты

> 📖 Рецепты

Кнопки:

- ⭐ Мои
- 🔎 Найти рецепт
- 🌾 Зерновые
- 🍎 Фруктовые
- 🍬 Сахарные
- ➕ Свой рецепт
- 🏠 Меню

Категории можно изменить после появления реального каталога. Не нужно заранее создавать слишком много категорий.

## Экран 5.2 — Список рецептов

Пример:

> 🌾 Зерновые рецепты

Кнопки:

- 🥃 Бурбон
- 🥃 Ржаной дистиллят
- 🥃 Пшеничный дистиллят
- → Далее
- ← Рецепты

## Экран 5.3 — Карточка рецепта

Пример:

> 📖 Бурбон
>
> На 30 л
>
> 🌾 Кукуруза — …
> 🌾 Солод — …
> 💧 Вода — …
> 🧫 Дрожжи — …
>
> Ориентировочное время: …

Основные кнопки:

- ▶️ Начать напиток
- 🧮 Пересчитать
- ⭐ Сохранить
- ⋯ Подробнее
- ← Назад

Если рецепт уже сохранён, кнопка `⭐ Сохранить` заменяется на понятное состояние, например `✓ В моих`.

## Экран 5.4 — Пересчёт рецепта

Если оборудование известно:

> 🧮 Пересчитать рецепт
>
> Ваш ферментер: 32 л
> Рекомендуемый рабочий объём: 27 л

Кнопки:

- ✅ На 27 л
- ✏️ Другой объём
- ← Назад

Если оборудования нет:

> На какой объём пересчитать рецепт?

Пользователь вводит значение вручную.

После расчёта бот показывает обновлённые количества и предлагает:

- ▶️ Начать с этими параметрами
- ⭐ Сохранить копию
- ← К рецепту

## Экран 5.5 — Начать напиток по рецепту

При нажатии `▶️ Начать напиток` бот не должен повторно спрашивать всё содержимое рецепта.

Минимальный сценарий:

> Создать напиток по рецепту «Бурбон»?
>
> Объём: 27 л
> Оборудование: Ферментер 32 л

Кнопки:

- ✅ Создать
- ⚙️ Изменить оборудование
- 🧮 Изменить объём
- ← Назад

После создания:

`→ 4.4 Карточка напитка`

## Экран 5.6 — Свой рецепт

Создание пользовательского рецепта должно быть пошаговым, но разрешать сохранить черновик.

Минимально:

1. Название.
2. Категория.
3. Базовый объём.
4. Ингредиенты.
5. Краткие этапы.

Расширенные поля не нужны в первой версии.

# 6. Калькуляторы

## Экран 6.1 — Калькуляторы

> 🧮 Калькуляторы
>
> Что нужно посчитать?

Кнопки:

- 💧 Разбавление
- 🥃 Смешивание крепостей
- 📐 Абсолютный спирт
- 🌡 Поправка спиртометра
- 📦 Выход продукта
- 📖 Пересчёт рецепта
- 🏠 Меню

Если кнопок становится слишком много, разбить на две страницы, а не добавлять сложную вложенную структуру.

## Экран 6.2 — Контекст калькулятора

Если у пользователя есть активные напитки, калькулятор может предложить:

> Для чего считаем?

Кнопки:

- 🥃 Бурбон
- 🥃 Кальвадос
- Ввести вручную
- ← Назад

Это необязательный шаг. Если калькулятор проще запустить сразу вручную — лишний экран не нужен.

## Экран 6.3 — Пример: разбавление

Если выбран напиток и его данные известны:

> 💧 Разбавление
>
> Бурбон
> Сейчас: 4.3 л · 76%
>
> До какой крепости разбавить?

Кнопки:

- 40%
- 42%
- 45%
- ✏️ Другая
- ← Назад

Результат:

> ✅ Расчёт
>
> Добавить воды: …
> Итоговый объём: …

Кнопки:

- 💾 Сохранить в напиток
- 🔁 Новый расчёт
- ← Калькуляторы

Если расчёт не относится к напитку, кнопка сохранения не показывается.

Главный UX-принцип калькуляторов: **один вопрос → один ответ**, без больших форм.

# 7. Оборудование

## Экран 7.1 — Моё оборудование

Если оборудования нет:

> ⚙️ Оборудование
>
> Добавьте своё оборудование один раз — бот сможет учитывать его в рецептах и расчётах.

Кнопки:

- ➕ Добавить
- 🏠 Меню

Если оборудование есть:

> ⚙️ Моё оборудование
>
> 🛢 Куб · 37 л
> 🪣 Ферментер · 32 л
> 🔥 ТЭН · 3 кВт

Кнопки:

- 🛢 Куб 37 л
- 🪣 Ферментер 32 л
- 🔥 ТЭН 3 кВт
- ➕ Добавить
- 🏠 Меню

## Экран 7.2 — Что добавить

> ➕ Оборудование
>
> Что хотите добавить?

Кнопки:

- 🛢 Перегонный куб
- 🪣 Ферментер
- 🧱 Колонна
- 🔥 Нагрев
- Другое
- ← Назад

## Экран 7.3 — Добавление оборудования

Запрашиваем только основные параметры.

Пример для куба:

> 🛢 Перегонный куб
>
> Укажите объём, л

После ввода:

> ✅ Куб 37 л добавлен

Кнопки:

- ➕ Добавить ещё
- ← Моё оборудование

Дополнительные параметры можно заполнить позже через карточку оборудования.

## Экран 7.4 — Карточка оборудования

> 🛢 Перегонный куб
>
> Объём: 37 л
> Название: Основной куб

Кнопки:

- ✏️ Изменить
- 🗑 Удалить
- ← Оборудование

В дальнейшем здесь можно добавить специфические параметры, но только если они реально используются ботом.

# 8. Завершение напитка и история

## Экран 8.1 — Завершить напиток

Когда пользователь переводит напиток в состояние `Готово`:

> ✅ Бурбон готов
>
> Сохранить итоговый результат?

Кнопки:

- ⭐ Оценить
- ✅ Просто завершить
- ← Назад

Не заставлять пользователя обязательно проходить дегустационную анкету.

## Экран 8.2 — Короткая оценка

Для MVP достаточно:

> Как вам результат?

Кнопки:

- ⭐⭐⭐⭐⭐
- ⭐⭐⭐⭐
- ⭐⭐⭐
- ⭐⭐
- ⭐

После выбора:

> Хотите добавить заметку?

Кнопки:

- 📝 Добавить
- Пропустить

Позже оценку можно расширить ароматом, вкусом и послевкусием.

## Экран 8.3 — История

История не обязана быть отдельным пунктом главного меню. Она открывается из `Напитки`.

Например внизу списка:

- 📚 Завершённые

Экран:

> 📚 Завершённые напитки
>
> ⭐ 5 · Бурбон · 24 августа
> ⭐ 4 · Кальвадос · 2 августа

Кнопки ведут в обычную карточку напитка в режиме просмотра истории.

# 9. Навигация

## Главное правило

Пользователь не должен думать, какую Telegram-команду вводить.

`/start` используется как техническая точка входа, но после запуска весь интерфейс работает кнопками.

## Кнопка «Назад»

Возвращает на один логический уровень вверх, а не обязательно к предыдущему сообщению в Telegram.

Пример:

`Замер → Карточка напитка → Список напитков → Главное меню`

## Кнопка «Меню»

Всегда возвращает на главный экран.

Она нужна на основных разделах и глубоких экранах, но не обязательно должна занимать место на каждом маленьком подтверждении.

## Отмена текстового ввода

Когда бот ждёт текст или число, под сообщением должна оставаться кнопка:

- ❌ Отмена

Она возвращает пользователя в предыдущий логический экран.

---

# 10. Что не должно попадать в главное меню

Даже если эти функции появятся, для них не нужны отдельные главные кнопки:

- напоминания;
- замеры;
- журнал;
- история;
- дегустации;
- статистика;
- запасы;
- настройки конкретного напитка;
- пересчёты рецепта.

Они открываются из соответствующего контекста.

Это критично для сохранения простого интерфейса.

# 11. Основные пользовательские сценарии MVP

## Сценарий A — первый запуск

`/start → Начать → Добавить оборудование / Пропустить → Главное меню`

## Сценарий B — найти рецепт и начать напиток

`Главное меню → Рецепты → Категория → Рецепт → Пересчитать под оборудование → Начать напиток → Карточка напитка`

## Сценарий C — создать напиток вручную

`Главное меню → Напитки → Новый напиток → С нуля → Название → Тип → Карточка напитка`

## Сценарий D — добавить замер

`Главное меню → Напитки → Напиток → Замер → Тип замера → Значение → Карточка напитка`

## Сценарий E — воспользоваться калькулятором

`Главное меню → Калькуляторы → Разбавление → Выбрать напиток / вручную → Ввести недостающие данные → Результат`

## Сценарий F — завершить напиток

`Карточка напитка → Следующий этап → Готово → Оценить / Завершить → История`

# 12. Границы MVP интерфейса

На первом этапе не нужны:

- сложные графики;
- социальные функции;
- рейтинги пользователей;
- публичные профили;
- маркетплейс рецептов;
- сложная система тегов;
- десятки типов оборудования;
- десятки параметров каждого устройства;
- отдельная административная панель внутри пользовательского меню;
- AI-чат как центральный элемент интерфейса.

Сначала бот должен идеально выполнять простую цепочку:

**нашёл рецепт → адаптировал под своё оборудование → начал напиток → сохранил замеры → воспользовался расчётами → завершил → сохранил результат.**

Если эта цепочка удобна, остальные функции можно добавлять вокруг неё без переделки базового UX.
